# Impeccable

## Design Context

### Users
Desarrolladores frontend (React/Angular) evaluando una librería de data grid para apps de negocio (ERP, CxC, dashboards internos). Llegan desde npm o GitHub, quieren ver la tabla funcionando en vivo y leer la API sin fricción. Contexto: escritorio, horario laboral, comparando contra AG Grid / TanStack Table.

### Brand Personality
Precisa, austera, artesanal. "Cero dependencias de peso, todo código propio" es el orgullo de la marca. Debe sentirse como una herramienta bien afilada, no como un producto SaaS.

### Aesthetic Direction
- Minimalismo blanco y negro estricto (tinta sobre papel / fósforo sobre negro). Nada de color de acento salvo el que la demo del grid trae por sus propias variables.
- Tipografía tipo consola en todo el sitio (mono display + mono/texto legible para cuerpo).
- Modo light y dark con toggle, ambos de primera clase.
- Sin emojis. Sin iconos decorativos gigantes. Sin gradientes, sin glassmorphism, sin cards dentro de cards.
- Animaciones funcionales únicamente: revelan estado, entradas escalonadas al cargar, feedback de interacción. Nada ornamental.
- Anti-referencias: landing genérica de IA (hero centrado + 3 cards con icono + gradiente morado), sitios de SaaS con glow.

### Design Principles
1. La demo en vivo ES el hero — el producto se demuestra, no se describe.
2. Todo en una tinta: jerarquía por tamaño, peso y espacio, no por color.
3. Densidad de manual técnico: tablas de API reales, texto que gana su lugar.
4. Movimiento solo donde comunica (estado, entrada, foco).
5. Ambos temas (papel / fósforo) diseñados a propósito, no invertidos automáticamente.
